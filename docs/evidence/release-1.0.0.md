# Aureus 1.0.0 verification summary

## Formal release

[Aureus 1.0.0 / build 1](https://github.com/freeforest/Aureus/releases/tag/v1.0.0) was publicly released on September 14, 2026 as a formal, non-prerelease version and was verified as Latest at release closure.

This was a **user-exception release**. Publication completion does not change overall technical evidence from **PARTIAL**, or repository-history safety from **NOT VERIFIED**.

## Completed delivery checks

The accepted release-closure record verifies public repository and release access, formal release identity, Latest, and anonymous downloads of the three hand-uploaded assets. Each download matched its fixed size and SHA-256, and the downloaded checksum file validated both archives.

The v1.0.0 source Tag and automatic source archive were checked against the approved 110-file release snapshot. The clean release snapshot and the repository's broader development history are different scopes. The already-published assets and snapshot are unchanged by the presentation documentation.

Get the [DMG, source ZIP, and checksum list](../distribution.md#official-100--build-1). These are inherited release-delivery facts, not a new build, download acceptance run, or App launch performed for this documentation.

## Product and distribution limits

- Official binary maintenance: Apple Silicon / arm64, with macOS 14.0 as the minimum deployment target; no all-device test claim.
- Signing: local ad-hoc, no Developer ID, no Apple notarization.
- License: MIT for Aureus-owned source; third-party licenses remain separate, as do Provider data and credential rights.
- Some old stage labels remain visible in the App as known legacy wording.

## Unfinished verification

Remaining manual checks, performance validation, log-privacy validation, and final-App runtime verification were accepted as unfinished. This includes unclosed interaction/accessibility and recovery-cancellation observations; a successful publication or checksum does not close them.

Historical Unit evidence and bounded synthetic/manual observations retain their original scope. No historical test count is presented here as a test run of the final 1.0.0 binary. User-reported observations are not proof of real-network behavior or complete runtime coverage.

The existing repository was made public under an explicit exception for disclosed, unverified history. In particular, the historical default.profraw content, origin, and public suitability remain NOT VERIFIED. No claim of a complete historical safety audit or absence of sensitive history is made.
